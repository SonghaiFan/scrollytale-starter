## A shared scale, a different experience

These **fictional housing index values** demonstrate a storytelling template.
They are not market statistics. Each region has four observations, from 2019 to 2022.

The text is Markdown. The charts are native VisDelta states.
This example uses continuous scroll progress. Scroll to move between the charts; the animation follows your scroll position.

<details>
<summary>The author’s ingredients</summary>

```js
const all = line(rows)
  .x('year')
  .y('value', { domain: [0, 120] })
  .breakdown('region')
  .color('region')

const highlighted = all.highlight({ region: 'Inner' })
```

</details>
