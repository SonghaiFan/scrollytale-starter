# Chart change, told as a story

The VisDelta homepage demonstrations, retold in MDX. The same data and native chart declarations now advance as you read.
These are illustrative example values, not a sourced statistical report.

[Bar](#home-bar) · [Line](#home-line) · [Area](#home-area) · [Point](#home-point) · [Unit](#home-unit) · [Scroll story](#home-products)

The five chart stories use **Step playback**: enter a new paragraph, then stop scrolling and watch the change finish. The final product story uses **Scroll progress**: stop scrolling to hold any frame.

## Bar

<Scrolly id="home-bar" title="Bar: code drives the chart">
  <Step chart={barBase}>

### Begin with the declaration

The starting chart from the homepage. Each following step adds one native method.

```js
const chart = bar(rows).x("year").y("sites").breakdown("country")
```

  </Step>
  <Step chart={barBase.color("country")}>

### Distinguish the countries

Color gives each country a consistent identity.

```js
.color("country")
```

  </Step>
  <Step chart={barBase.color("country").layout("grouped")}>

### Compare side by side

Move from stacked totals to grouped bars.

```js
.layout("grouped")
```

  </Step>
  <Step chart={barBase.color("country").layout("grouped").flip()}>

### Turn the chart

Exchange the horizontal and vertical directions.

```js
.flip()
```

  </Step>
</Scrolly>

## Scroll is a timeline

The homepage’s product story. Here your scroll position drives the frames directly; read upward to retrace them.

<Scrolly id="home-products" title="Revenue, profit and attention" mode="scroll" hold={0}>
  <Step chart={revenue}>

### Revenue by product

One state: data and mappings. Hardware has the highest revenue.

```js
const a = bar(products).x('product', { label: 'Product' })
  .y('revenue', { label: 'Revenue ($M)' }).key('product')
```

  </Step>
  <Step chart={profit}>

### Show profit instead

Change the measure. The bars, axis and title move together. Software now leads.

```js
const b = a.y('profit', { label: 'Profit ($M)' })
```

  </Step>
  <Step chart={ranked}>

### Rank it

The same products move into descending profit order. No records change.

```js
const c = b.sort('profit', 'descending')
```

  </Step>
  <Step chart={ranked.highlight({ product: ['Software', 'Cloud'] })}>

### Point at two of them

Highlight Software and Cloud. Nothing leaves the chart; only attention changes.

```js
const d = c.highlight({ product: ['Software', 'Cloud'] })
```

  </Step>
</Scrolly>
